# Add the XP block

The XP block shows learners their points and level. The [XP mode](../context/index.mdx) controls where you can add the block:

- In per-course mode, add the block to each course where you use XP.
    - If the [overall level](../context/global-level.mdx) is enabled, you can also add the block to **Site home** or **Dashboard**.
- In sitewide mode, add the block to **Site home**, the default **Dashboard**, or another page. All XP blocks show the same sitewide data.

## Add the block to a course or page

1. Open the course or page where you want to add the block.
2. Turn editing on.
3. Select **Add a block**.
4. Select **Level Up XP**.

To show the block on more pages, change the settings under **Where this block appears**. For more information, see [block settings in the Moodle documentation](https://docs.moodle.org/en/Block_settings).

## Add the block to every user's Dashboard

You must be a site administrator to add the block for all users. Use the **Default Dashboard page** to do this. If you add the block to your own **Dashboard**, only your **Dashboard** changes.

1. Open **Site administration > Appearance > Default Dashboard page**.
2. Turn block editing on.
3. Select **Add a block**.
4. Select **Level Up XP**.
5. Move the block to the required location.
6. To apply the change to existing users, select **Reset Dashboard for all users**.

## If the block is not available

If **Level Up XP** is not in the **Add a block** list, do these checks:

- Check whether the XP block is already on the page.
- Make sure that you can add the block to the page in the selected [XP mode](../context/index.mdx).
- Make sure that your role has the [`block/xp:addinstance` permission](../permissions.mdx#addinstance).
- Ask an administrator to [check the block status](#check-the-block-status) and make sure that it is enabled and unlocked.

### Check the block status

1. Open **Site administration > Plugins > Blocks > Manage blocks**.
2. Find **Level Up XP** in the list.
3. If the block is disabled, enable it.
4. If the block is locked, unlock it.

If **Level Up XP** is not in the list, make sure that [XP is installed](./index.mdx).
