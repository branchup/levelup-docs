# Uninstall Level Up XP

If XP and XP+ are installed, uninstall XP+ first. Then uninstall XP.

:::danger

Moodle permanently deletes the data stored by each plugin that you uninstall. Back up your Moodle site before you continue.

:::

<span id="xpplus"></span>

## Uninstall XP+

1. Open Site administration > Plugins > Plugins overview.
2. Find Level Up XP+ (`local_xp`) in the list of plugins.
3. Select Uninstall and follow the uninstall process.
4. If Moodle asks you to remove the plugin files, remove `[public]/local/xp`.

<span id="xp"></span>

## Uninstall XP

:::info

Before you uninstall XP, uninstall the following plugins if they are installed:

- Uninstall Level Up XP+ (`local_xp`).
- Uninstall Level Up XP Enrol (`enrol_xp`).
- Uninstall Level Up XP Availability (`availability_xp`).

:::

1. Open Site administration > Plugins > Plugins overview.
2. Find Level Up XP (`block_xp`) in the list of plugins.
3. Select Uninstall and follow the uninstall process.
4. If Moodle asks you to remove the plugin files, remove `[public]/blocks/xp`.

:::warning

If Uninstall is not available, a dependent plugin might still be installed. If you removed all dependent plugins, [orphan blocks](../../troubleshooting/block-cannot-be-deleted/index.mdx) might prevent the uninstall.

:::
