# Install Level Up XP

You can install XP by itself or add XP+ for more features.

## Get the plugins

| Plugin | Code name | How to obtain |
| --- | --- | --- |
| XP (required) | `block_xp` | Download the ZIP file from the [Level Up website](https://www.levelup.plus/xp/#packages), [CAMP](https://camp-registry.org/plugin/block_xp.html), or the [Moodle plugins directory](https://moodle.org/plugins/block_xp). You can also use the Git method below. |
| XP+ (optional) | `local_xp` | Purchase an XP+ licence from the [Level Up website](https://www.levelup.plus/xp/#packages). You will receive an email with a link to download `local_xp.zip`. If you lost the link, use the [licence recovery tool](https://levelup.plus/recover). |

:::tip

If XP is already installed, do not install it again. Install only XP+. Moodle will tell you if you must [upgrade XP](./upgrading.mdx) first.

:::

## Installation

Choose an installation method.

<Tabs>
  <TabItem value="zip" label="ZIP upload" default>
    <Admonition type="note">
      This method is not available on all Moodle sites. Its availability depends on the site configuration and hosting provider.
    </Admonition>

    1. Sign in to your Moodle site and open Site administration > Plugins > Install plugins.
    2. Upload the XP ZIP file and follow the installation process. Skip this step if XP is already installed.
    3. If you use XP+, upload `local_xp.zip` and follow the installation process.
  </TabItem>

  <TabItem value="server" label="Server files">
    1. Extract the XP ZIP contents into `[public]/blocks/xp`. Skip this step if XP is already installed.
    2. If you use XP+, extract the contents of `local_xp.zip` into `[public]/local/xp`.
    3. Confirm that each plugin folder contains a `version.php` file.
    4. Open Site administration > Notifications and follow the installation process.
  </TabItem>

  <TabItem value="git" label="Git">
    This method installs XP only.

    1. From the Moodle root directory, go to `[public]/blocks` or `blocks`.
    2. Clone the [official XP repository](https://github.com/FMCorz/moodle-block_xp) into a folder named `xp`.
    3. Check out the latest release tag.
    4. Open Site administration > Notifications and follow the installation process.

    The following commands clone the official repository and check out the latest tag.

    ```sh
    cd public/blocks 2>/dev/null || cd blocks || exit 1
    git clone https://github.com/FMCorz/moodle-block_xp.git xp
    cd xp
    git checkout "$(git tag --list 'v*' --sort=-v:refname | head -n 1)"
    ```
  </TabItem>
</Tabs>

## Recommended plugins

The following free plugins add optional features:

- XP Availability lets instructors restrict access to course content according to a learner's level.
- XP Enrol lets instructors enrol learners in a course when they reach a specified level in another course.
- Shortcodes lets instructors add XP content to Moodle text areas.

[Install the recommended plugins](./recommended-plugins.mdx) that provide the features you need.
