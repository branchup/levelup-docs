# Level in navigation bar

You can show learners their level in the navigation bar.

<Screenshot img={require('./navbar-wide.png')}>
  The Boost theme shows the level next to the user's profile in the navigation bar.
</Screenshot>

## Which level appears?

The level in the navigation bar depends on the [XP mode](../context/index.mdx) and the page that the learner opens.

- In **In courses** mode, the navigation bar shows the level for the current course. The displayed level can change when the learner opens another course.
- In **Sitewide** mode, the navigation bar shows the same sitewide level on all pages.
- With an [overall level](/xp/docs/global-level), the navigation bar shows the overall level outside courses and the course level inside each course.

## Enable the display

An administrator must enable this feature.

1. Go to **Site administration > Plugins > Blocks > Level Up XP > General settings**.
2. Set **Show level in navbar** to **Yes**.
3. Select **Save changes**.
4. Check that the level appears correctly in the navigation bar and that the rest of the page displays correctly.

## Always show the overall level

Switching between course levels and the overall level can confuse learners. If you use an overall level, you can keep it in the navigation bar as learners move between pages.

1. Go to **Site administration > Plugins > Blocks > Level Up XP > General settings**.
2. Set **Overall level in navbar** to **Yes**.
3. Select **Save changes**.

This setting is optional. It makes the navigation bar show the overall level everywhere, including inside courses. The XP block in each course continues to show the course level.

## Theme compatibility

The navigation bar display depends on your theme. Some themes might not support it.

If the level does not appear or displays incorrectly, contact your theme designer.
