# Unlock an activity at a specified level

Use level restrictions to make activities and resources available when learners reach a specified level. This helps you control access to course content and reward learners for their progress.

:::info

To use this feature, install and enable [XP Availability](../../getting-started/installation/recommended-plugins.mdx#xp-availability). You must also enable the Moodle setting `enableavailability`.

:::

1. Open the settings for the activity or resource.
2. Expand Restrict access.
3. Select Add restriction, and then select Level.
4. Select the required level and save the changes.

<Screenshot img={require('./level-up-access-restriction.png')}>Learners can access the activity when they reach level 5.</Screenshot>

For more information, see [Restrict access settings](https://docs.moodle.org/en/Restrict_access_settings) in the Moodle documentation.

:::tip

You can also apply this restriction to a whole course section.

:::
