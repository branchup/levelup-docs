# Enrol learners at a specified level

The level enrolment method automatically enrols learners in a course when they reach a specified level. Use it to control access to advanced courses and reward learner progress.

:::info

To use this feature, install and enable [XP Enrol](../../getting-started/installation/recommended-plugins.mdx#xp-enrol).

:::

1. Open the course in which you want to enrol learners.
2. Open the Enrolment methods page:
   - In some versions of Moodle, select Course administration > Enrolment methods.
   - In other versions of Moodle, select Participants > Enrolment methods.
3. In Add method, select Level Up XP Enrolment.
4. In Level to attain, enter the required level.
5. If Level Up XP is not in [Sitewide mode](../../getting-started/per-course-or-site.mdx)…
   - Find Course to attain level in.
   - Select the course in which learners must reach the level.
6. If necessary, enter a welcome message.
7. Save the changes.

<Screenshot img={require('./level-up-course-restriction-enrol.png')}>These settings enrol learners when they reach level 5.</Screenshot>

For more information, see [Enrolment plugins](https://docs.moodle.org/en/Enrolment_plugins) in the Moodle documentation.
