# The block cannot be deleted

A sitewide XP block can remain on a page after you change XP to per-course mode. The delete action is then not available because the page does not match the configured [XP mode](../../getting-started/per-course-or-site.mdx).

Temporarily change XP to sitewide mode to delete the block.

## Delete the block

1. Open Site administration > Plugins > Blocks > Level Up XP > General settings.
2. Change XP to sitewide mode.
3. Open the page that contains the XP block.
4. Turn editing on.
5. Delete the Level Up XP block.
6. Repeat steps 3 through 5 for each block that you cannot delete.
7. Open the Level Up XP general settings again.
8. Change XP back to per-course mode.
