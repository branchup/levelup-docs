# The block cannot be added

Use these checks if Level Up XP does not appear in the Add a block list.

## Check the page

The [XP mode](../../getting-started/per-course-or-site.mdx) controls where you can add the block:

- In per-course mode, add the block inside a course. It does not appear on the Site home or Dashboard.
- In sitewide mode, you can add the block to the Site home, a Dashboard, a course, or another page.

If you need the block on the Site home or Dashboard, ask an administrator to enable sitewide mode.

## Check your permissions

To add the block to a course or another page, your role must have the `block/xp:addinstance` capability.

For Dashboard use, an administrator must [add the block to the default Dashboard](../../getting-started/installation/adding-the-block.mdx#add-the-block-to-every-users-dashboard) for all users.

For more information, see [XP permissions](../../getting-started/permissions.mdx).

## Check the block status

Ask a site administrator to complete these steps:

1. Open Site administration > Plugins > Blocks > Manage blocks.
2. Find Level Up XP in the list.
3. Confirm that the block is enabled.
4. Confirm that the block is unlocked. If it is locked, unlock it.
5. Return to the page where you want to add the block and try again.

If Level Up XP is not in the list of blocks, confirm that [XP is installed](../../getting-started/installation/index.mdx).
