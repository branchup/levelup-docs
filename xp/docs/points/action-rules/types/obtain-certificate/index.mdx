Use the Obtain a certificate action to award points when the Custom certificate plugin issues a certificate to a learner.

## Requirements

You must use the following software:

- Moodle 5.0 or later.
- [Custom certificate](https://camp-registry.org/plugin/mod_customcert.html) version 5 or later.

## Configure the action

1. Go to the Action rules page.
2. Select Add action and then select Obtain a certificate.
3. Add the Specific activity condition.
4. Select the certificate activity, such as Program certificate.
5. Enter the number of points to award.

Level Up XP awards the specified points when the selected activity issues a certificate to a learner.
