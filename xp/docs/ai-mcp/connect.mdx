# Connect your AI assistant

:::info[Under development]

We will release this feature with XP+ v21.

:::

Before you start, ask your Moodle administrator to confirm that:

- AI and MCP access is enabled in Level Up XP
- You have permission to use the integration
- Your AI assistant is approved by your organisation

You will also need the Level Up XP MCP URL for your Moodle site. It normally
looks like this:

```text
https://moodle.example.com/blocks/xp/mcp.php
```

Replace `https://moodle.example.com` with the address of your Moodle site.

## Connect ChatGPT

We are submitting Level Up XP to the ChatGPT plugin directory. After OpenAI
publishes Level Up XP, you can install it without creating a custom app. ChatGPT
plugins are available in ChatGPT Work on the web and in the desktop app. Your
workspace settings can restrict access to plugins.

After OpenAI publishes Level Up XP, use these steps:

1. Open Plugins.
2. Search for Level Up XP and open its details.
3. Select the plus button to install the plugin.
4. Follow the prompts to enter your Level Up XP MCP URL and connect the plugin.
5. Sign in to Moodle and review the authorisation request.
6. Approve the request only if it shows the correct Moodle site and ChatGPT
   workspace.
7. Start a new chat and ask ChatGPT to use Level Up XP.

For more information, refer to
[OpenAI's instructions for ChatGPT plugins](https://learn.chatgpt.com/docs/plugins).

## Connect Claude

If you use an individual Claude account:

1. Open Customize > Connectors.
2. Select +, then Add custom connector.
3. Name the connector `Level Up XP` and enter your Level Up XP MCP URL.
4. Leave all other settings unchanged, then add the connector.
5. Select Connect, then sign in to Moodle.
6. Review and approve the authorisation request.

If you use a Claude Team or Enterprise account, ask an owner to add the
connector under Organization settings > Connectors. The owner must leave all
other settings unchanged. You can then find the connector under Customize >
Connectors and select Connect.

When you start a conversation, use + > Connectors to make Level Up XP available
in that conversation.

Refer to
[Claude's current custom connector instructions](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)
if the options in your account differ.

## Connect another assistant

You can connect another AI assistant if it supports remote MCP servers with
OAuth authentication.

In the assistant's MCP or connector settings:

1. Add a remote MCP server.
2. Enter a name and the Level Up XP MCP URL.
3. Choose `Streamable HTTP` as the MCP connection type.
4. Choose OAuth authentication.
5. Sign in to Moodle and approve access.

If the assistant asks for an OAuth client ID, client secret or redirect URL,
contact your Moodle administrator. The administrator may need to
[register the assistant manually](./admin.mdx#oauth-clients).

Never enter your Moodle password directly into an AI conversation or store it
in an MCP configuration file. The connection should send you to your Moodle
site to sign in.

## Check the connection

Start with a request that does not make changes:

> Show me the Level Up XP levels for [course name]. If XP is used sitewide,
> show me the sitewide levels. Do not make any changes.

If the assistant cannot find Level Up XP, make sure the connection is enabled
for the conversation. If it connects but cannot complete the request, see
[Troubleshooting](./troubleshooting.mdx).
