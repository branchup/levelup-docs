# Connect your AI assistant

:::info[Under development]

We will release this feature with XP+ v21.

:::

Before you start, ask your Moodle administrator to confirm that:

- AI and MCP access is enabled in Level Up XP
- You have permission to use the integration
- Your AI assistant is approved by your organisation

To connect ChatGPT or Claude, you will also need the Level Up XP MCP URL for
your Moodle site. It normally looks like this:

```text
https://moodle.example.com/blocks/xp/mcp.php
```

Replace `https://moodle.example.com` with the address of your Moodle site.

## Connect ChatGPT

Add your Moodle site's MCP server to ChatGPT as a plugin.

1. Open **Plugins**.
2. Select the plus (**+**) button. If the button is not visible, open
   **Settings** > **Security and login**, turn on **Developer mode**, then
   return to **Plugins**.
3. Name the plugin `Level Up XP` and enter your Level Up XP MCP URL under
   **Connection**.
4. Leave all other settings unchanged, then select **Create**.
5. Select **Sign in with Level Up XP**, then sign in to Moodle.
6. Review and approve the authorisation request.

When you start a conversation, add Level Up XP from the tools menu.

For more information, refer to
[OpenAI's instructions for connecting an MCP
server](https://developers.openai.com/plugins/deploy/connect-chatgpt#add-the-mcp-server).

## Connect Claude

If you use an individual Claude account:

1. Open **Customize** > **Connectors**.
2. Select the plus (**+**) button, then **Add custom connector**.
3. Name the connector `Level Up XP` and enter your Level Up XP MCP URL.
4. Leave all other settings unchanged, then add the connector.
5. Select **Connect**, then sign in to Moodle.
6. Review and approve the authorisation request.

If you use a Claude Team or Enterprise account, ask an owner to add the
connector under **Organization settings** > **Connectors**. The owner must
leave all other settings unchanged. You can then find the connector under
**Customize** > **Connectors** and select **Connect**.

When you start a conversation, use **+** > **Connectors** to make Level Up XP
available in that conversation.

Refer to
[Claude's current custom connector instructions](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)
if the options in your account differ.

## Connect another assistant

Your Moodle administrator must register and configure another assistant before
you can use it with Level Up XP. You cannot connect it only by entering the MCP
URL.

1. Open **Level Up XP** and select **AI**.
2. In **Connect an AI assistant**, follow the instructions from your
   administrator.
3. If there are no instructions for your assistant, contact your
   administrator.

The instructions can direct you to an assistant that your organisation already
provides.

Never enter your Moodle password directly into an AI conversation or store it
in an MCP configuration file. The connection should send you to your Moodle
site to sign in.

## Check the connection

Start with a request that does not make changes:

> Show me the Level Up XP levels for [course name]. If XP is used sitewide,
> show me the sitewide levels. Do not make any changes.

If the assistant cannot find Level Up XP, make sure the connection is enabled
for the conversation. If it connects but cannot complete the request, see
[Troubleshooting](./troubleshooting.mdx).

## Revoke access

Disconnecting an AI assistant does not always revoke its access in Moodle. To
revoke all AI access for your Moodle account:

1. Open **Level Up XP** and select **AI**.
2. In **Current AI access**, select **Revoke all AI access**.
3. Confirm the action.

All AI assistants will lose access to Level Up XP through your Moodle account.
You must authorise a new connection before you can use Level Up XP with an
assistant again.
